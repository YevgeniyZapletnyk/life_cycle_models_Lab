# Алгоритми та взаємодія

`index.html` підключає data → math → chart → app. Контролер отримує незмінні дані або перевіряє ручне введення. Обчислювальний модуль повертає функції обчислення поліномів і метрики. Chart отримує готові серії, обчислює межі X/Y, малює Canvas і обслуговує підказки.

Лагранж: нормовані вузли → барицентричні ваги O(n²) → оцінка полінома O(n) на відлік. Вузловий аргумент обробляється окремо. Ньютон незалежно будує таблицю поділених різниць O(n²).

МНК: нормалізація x → дизайн-матриця → відбиття Хаусхолдера до A і y → зворотна підстановка → прогнози, залишки та метрики. Нормальні рівняння не формуються. Складність O(n(m+1)²).

Анімація зберігає p ∈ [0;1]. Лагранж плавно переходить між поліномами через перші k вузлів. МНК зростає від середнього y, залишки з’являються з 55 % шкали. Кожний кадр наново обчислює межі видимих серій. Для майже нульових залишків застосовується мінімальний діапазон Y.

Перевірено 23 чисельні тести й 22 перевірки в браузері: три набори, режими, залишки, анімація/пауза/перемотування, валідація, парабола, скидання, екстраполяція, вузький екран. Під час перевірки виправлено прийняття порожньої координати та переповнення ширини CSS Grid.

Звіт, сценарій захисту, знімки екрана та локальні допоміжні матеріали зберігаються поза репозиторієм Code.
