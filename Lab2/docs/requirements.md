# Технічне завдання

Мета: порівняти прямий та ітераційні методи для варіанта 3.

| ID | Вимога | Перевірка |
|---|---|---|
| F1 | Генерація 5/10/20, d=1/0.1, b=A x* | 6 тестів генератора |
| F2 | Гаусс із частковим вибором по стовпцю | 6 систем, нульова діагональ, виродженість |
| F3 | Якобі, попередній вектор | 6 систем, ручна перша ітерація |
| F4 | Зейдель, нові компоненти | 6 систем, ручна перша ітерація |
| F5 | ε, ліміт ≥20000 у GUI, статуси | валідація, ліміт, розбіжність |
| F6 | Власні A,b і файли | текст, JSON, помилкові значення |
| F7 | 6 графіків, логарифмічна нев'язка | браузерна перевірка |
| F8 | Анімація, крок, пауза, автомасштаб | браузерна перевірка |
| F9 | Метрики, експеримент без вибору | metrics.json, NumPy |
| F10 | Документи, тести, AI-log | локальний комплект |

Чисельна арифметика: JavaScript Number (IEEE 754 binary64). Алгоритми реалізовано вручну.
Для порівняння використано NumPy лише в окремій перевірці. Точність за замовчуванням 1e-10.
Початковий вектор нульовий. Похибка приймання <1e-8, нев'язка <1e-8 на шести системах.
Програма повідомляє про чисельно вироджену матрицю, але не розрізняє несумісність і нескінченність розв'язків.
