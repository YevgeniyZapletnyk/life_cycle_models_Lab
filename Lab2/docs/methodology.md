# V-модель

Вимоги стабільні, точний розв'язок відомий. Головний ризик - прихована чисельна помилка.
Тому вимоги зіставлено з приймальними тестами, архітектуру - з інтеграційними,
детальні алгоритми - з модульними. На відміну від спрощеного Waterfall, перевірки
визначаються разом з відповідними рішеннями. Agile також можливий, але зміна вимог
не є центральним завданням цієї лабораторної. Spiral для цього масштабу надмірний.
