Заплетнюк Євгеній Сергійович. JavaScript, без бібліотек під час виконання.

## Запуск

Відкрити `index.html` у Chrome або Edge. Встановлення залежностей і сервер не потрібні.
У VS Code можна відкрити папку програми (`Code` локально або `Lab2` у репозиторії) і файл `index.html` у браузері.

Для Node.js (перевірено v24.21.0), з папки програми:

```text
node cli.js 5 1
node cli.js 20 0.1
node cli.js examples/system.json
node --test tests/math.test.js
node scripts/metrics.js
```

Команди npm: `npm test`, `npm run metrics`, `npm run demo`. Якщо PowerShell блокує npm.ps1, використати `npm.cmd test` або наведені команди node.

## Формули

Індекси i,j = 1..n, кути в радіанах. a_ij = cos(i+j) при i != j;
a_ii = sum(abs(a_ij), j != i) + d; x*_i = (-1)^i i; b = A x*.
n = 5, 10, 20; d = 1 або 0.1; eps = 1e-10; x0 = 0.
Зупинка ітерацій: max(abs(x_new - x_old)) < eps. Це не гарантія похибки < eps;
нев'язка L2 і похибка L∞ наведені окремо. Ліміт UI 20000..100000.

## Можливості

Шість графіків для всіх n; вибір d; фільтри методів; Гаусс із вибором по стовпцю;
Якобі, Зейдель; анімація, пауза, крок і повзунок; автоматичні межі X/Y;
введення розширеної матриці або JSON; імпорт TXT/CSV/JSON; експорт результатів;
експеримент з нульовим головним елементом. Зміна n обирає систему для анімації.

CSV використовує крапку як десятковий роздільник; кома, крапка з комою, пробіл і `|`
розділяють числа. JSON має поля A, b, необов'язково exact. Обмеження: 2..50 рівнянь,
файл до 1 МБ. Без exact похибка не обчислюється. Без діагональної переваги показується
попередження; нуль на діагоналі блокує ітерації. Перевищення ліміту не називається збіжністю.

## Перевірка

40 модульних тестів; 18 незалежних звірок із NumPy; 23 браузерні перевірки.
Ці перевірки виконано під час підготовки. Їхні журнали та звіти не входять до цієї публікації. `metrics.js` відтворює таблиці та зберігає їх у `results/metrics.json`:
20 прогрівальних і 200 виміряних повторів, без трасування; середній час, мс.
Час у GUI - окремий запуск зі збереженням кадрів, тому ці значення не тотожні.
