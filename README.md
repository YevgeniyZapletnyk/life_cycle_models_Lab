# Лабораторна робота № 1 — варіант 3

Апроксимація функцій: інтерполяція Лагранжа та МНК через QR-розклад Хаусхолдера.

Запуск: відкрийте `index.html` у сучасному браузері. Інтернет, сервер і встановлення пакетів не потрібні.
Перевірка (Node.js 20+): `npm test`. Аналітичні результати: `npm run metrics`.

Вихідні дані перенесено з наданої таблиці без зміни. Набір, названий у завданні «10 точок», фактично містить 8 пар; інтерфейс і звіт це явно позначають.

Репозиторій: https://github.com/YevgeniyZapletnyk/life_cycle_models_Lab

## Структура

- `js/data.js` — дані та перевірка введення.
- `js/math.js` — Лагранж, Ньютон, QR-МНК та метрики.
- `js/chart.js` — Canvas, масштаб, підказки.
- `js/app.js` — інтерфейс і шкала часу.
- `tests/` — автоматичні перевірки чисельних методів.
- `scripts/metrics.js` — відтворюваний аналіз наборів.
- `docs/` — технічне завдання та опис розробки.

Керування: набір 5 / 10 (8) / 20; режим Інтерполяція / МНК / Усі; степінь МНК 1–4; анімація, пауза, перемотування, швидкість; власні дані; екстраполяція. Окрема галерея показує шість кінцевих графіків.
