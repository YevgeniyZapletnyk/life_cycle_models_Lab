# Технічне завдання

Призначення: дослідження точності та стійкості однокрокових методів задачі Коші.
Основна задача: y′=y cos x, y(0)=2, [0;π]. Еталон: 2 exp(sin x).

| ID | Вимога | Перевірка |
|---|---|---|
| F1 | Ейлер, Хойн, РК4 | крок y′=y; порядок 1, 2, 4 |
| F2 | Strategy, додавання методу через реєстр | тест нової Midpoint-стратегії |
| F3 | n=5,10,20 і n+1 вузлів | тести сітки; браузер |
| F4 | Власні f, x0, y0, b, n та необов’язковий еталон | парсер, валідація, браузер |
| F5 | 3 графіки розв’язків і 3 похибок | галерея, браузер |
| F6 | Анімація, пауза, перемотування, швидкість, стадії РК4 | браузер |
| F7 | Автомасштаб обох осей на кожному кадрі | bounds, тест −243, браузер |
| F8 | max-похибка, кінцева похибка, час для n=5,10,20 | metrics.json |
| F9 | Відношення e(h)/e(h/2), експериментальний порядок | чисельні тести |
| F10 | Стійкість Ейлера для y′=−20y | кінцеві значення −243, 1, 0 |
| F11 | CSV із усіма вузлами | модульний тест і браузерне завантаження |
| F12 | Бонусна система Лотки–Вольтерри | додатність, рівновага, дрейф інваріанта |
| F13 | Документи, UML, тести, CI-конфігурація | технічна документація; тести; GitHub Actions |

Обмеження: сучасний браузер; n від 1 до 10000, b>x0, скінченні дані;
явні методи без автоматичного підбору кроку; сторонні ODE-розв’язувачі не використовуються.
Точний розв’язок власної задачі задає користувач. Переповнення зупиняє розрахунок.
Похибки вимірюються у вузлах. Час обчислення не включає графіки.
