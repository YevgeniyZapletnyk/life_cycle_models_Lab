# Архітектура

OdeMethod задає контракт `step(f,x,y,h) -> {y, stages}`. EulerMethod,
HeunMethod і RK4Method реалізують його. MethodRegistry зберігає стратегії.
CauchySolver залежить від контракту, а не від конкретного методу.
Контролер формує select із registry.list(): додавання стратегії не потребує
нової гілки switch або зміни HTML. РК4 має окрему необов’язкову візуалізацію стадій.

Парсер повертає перевірену функцію; CauchySolver створює n+1 вузлів і n кроків.
Аналіз виконується після побудови, похибки кешуються в `solution.error`.
На кадрі обрізаються видимі серії та перераховуються межі Canvas.
Проміжна позиція повзунка інтерполює відрізок для анімації, а не розв’язує нове ОДУ.

Складність інтегрування O(n) за часом і пам’яттю. На крок потрібно 1, 2 або 4
виклики правої частини. Система Лотки–Вольтерри інтегрується векторним РК4.
Поза допустимою областю або при переповненні видається помилка, експорт блокується.
