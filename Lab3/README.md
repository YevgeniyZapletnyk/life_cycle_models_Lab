# Лабораторна робота № 3 — варіант 3

Заплетнюк Євгеній Сергійович. Задача Коші: y′ = y cos(x), y(0) = 2, x ∈ [0; π].
Точний розв’язок: y = 2 exp(sin(x)).

## Запуск

Відкрийте `index.html` у Chrome, Edge або Firefox. Інтернет і сервер не потрібні.
У цьому репозиторії відкрийте `Lab3/index.html` після завантаження коду.

Перевірки з папки Lab3 (Node.js 20+):

```
node --test tests/math.test.js
node scripts/metrics.js
```

Також працюють `npm test` і `npm run metrics`. Якщо PowerShell блокує npm.ps1,
використовуйте `npm.cmd test`. Встановлювати npm-пакети для програми не потрібно.

## Можливості

- Ейлер, Хойн, РК4 через Strategy та MethodRegistry.
- Варіант 3; стійкість y′ = −20y; власна скалярна задача; бонус Лотки–Вольтерри.
- n = 5 / 10 / 20 та довільне ціле 1…10000; n+1 вузлів.
- Шість постійних графіків, основні анімовані графіки, проміжні оцінки РК4.
- Автомасштаб X/Y на кожному кадрі, логарифмічна шкала похибки.
- CSV UTF-8 з BOM, усі вузли та абсолютні похибки.
- Безпечний парсер: `+ - * / ^`, дужки, `sin cos tan exp log ln sqrt abs atan`, `pi e`.

У власній задачі десяткові числа записуйте через крапку, множення через `*`.
Поле точного розв’язку можна залишити порожнім. Тоді похибка і порядок недоступні.
Перевіряється початкова умова еталона, але тотожність ОДУ не доводиться автоматично.
Для n > 200 інтерфейс показує вибірку з 201 вузла; CSV містить усі вузли.
Ламані між вузлами служать візуалізацією; аналіз точності виконується у вузлах.
На логарифмічній шкалі нульові похибки пропущено, а не підмінено ненульовими.

## Файли

`js/methods.js` — стратегії; `solver.js` — інтегратор, похибки, CSV, система ОДУ;
`expr.js` — парсер; `problems.js` — задачі; `chart.js` — Canvas і межі;
`app.js` — керування; `tests/math.test.js` — чисельні тести;
`scripts/metrics.js` — відтворення таблиць у `results/`;
`docs/` — ТЗ, методологія, архітектура, алгоритми й UML.


## CI та походження позначень

Workflow [Lab 3 tests](../.github/workflows/lab3-tests.yml) запускає `npm test`
у папці Lab3 на Node.js 20, 22 і 24 при push або pull request зі змінами Lab3.
Аналітичні результати записуються у Lab3/results/ і не додаються до Git.

Коміти згруповано за 12 пунктами наданої автором Excel-декларації:
`[manual]` — пункти 1–3, 10–12; `[AI]` — пункт 5;
`[AI+edit]` — пункти 4, 6–9. Мітки відтворюють заявлений автором розподіл,
а не незалежну перевірку авторства. Початковий робочий комплект було створено
за допомогою Codex. Коміти додають уже підготовлені компоненти під час
публікації; історію дат розробки не реконструйовано.
Звіти DOCX/PDF, сценарій захисту й Excel до репозиторію не включено.
